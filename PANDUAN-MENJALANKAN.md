# Menjalankan Sadino Workplace v3.0.0
1. Ekstrak ZIP. 2. Di folder proyek: `cd frontend` lalu `python3 -m http.server 8080`. 3. Buka http://localhost:8080 di browser (HP: alamat IP laptop:8080 di jaringan yang sama).
4. Uji: `npm test` (Node) dan `python tests/e2e.py` (butuh Playwright).
Tanpa Python: unggah folder `frontend` ke hosting statis (mis. GitHub Pages).
Kinerja: pilih "Simulasi hidup (DEMO)" untuk melihat robot bergerak. Itu hanya tampilan, bukan kerja AI.
