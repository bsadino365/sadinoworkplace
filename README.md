# Bawaulin AI Workspace
Satu aplikasi, satu perusahaan virtual, banyak karyawan AI. Anda adalah CEO.

**Versi 1.1.0 = MVP frontend PWA** (offline, data di IndexedDB). Backend, Local Worker, GitHub Manager, AI Model Manager, dan integrasi OpenClaw/Hermes **belum dibuat**; semuanya tampil "Belum Terhubung". Lihat `docs/IMPLEMENTATION-STATUS.md`.

## Menjalankan
Buka folder `frontend/` lewat server statis (mis. GitHub Pages). Service worker butuh HTTPS atau localhost.
Uji: `node tests/logic.test.js` dan `node tests/render.test.js`.
